# 🌾 CropDoc - AI Crop Disease Detection

A real-time agricultural AI assistant that uses your device's camera to detect crop diseases and provide actionable treatment recommendations.

## Features

- **Live Camera Feed**: Real-time video capture with overlay
- **AI Disease Detection**: Simulated detection of common crop diseases
- **Diagnosis Panel**: Displays crop name, condition, confidence, and symptoms
- **Treatment Recommendations**: Both chemical and organic treatment options
- **Detection History**: Log of all scans with timestamps
- **Data Persistence**: Saves history locally in browser
